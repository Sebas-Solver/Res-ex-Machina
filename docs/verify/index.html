Verify a receipt

Checks an rxm-pog-v2 receipt in your browser against a public blockchain node. Res ex Machina's servers are not involved, and nothing you load here leaves your browser except the read-only queries to the node.

Drop the file here, or click to choose it

If you add the file, its SHA-256 is computed locally and compared with the declared content hash. The file is not uploaded.

    A valid result proves only what the statement says. The model, runtime, process and declared time are the signer's own claims, not verified facts.

    Open source verifier: @res-ex-machina/pog. Prefer the command line? rxm-verify receipt.json --content file.
