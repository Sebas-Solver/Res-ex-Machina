# Security Policy

## Status

Res ex Machina is a **prototype running on Base Sepolia testnet**. It is not production-ready and the hosted API is currently offline. Do not use it to protect funds or data of value.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private reporting instead:
**Security → Report a vulnerability** on this repository.

Include the affected component (API, SDK, MCP server, verifier, contracts), the version or commit, and the steps to reproduce. You can expect an acknowledgement within 7 days.

## How findings are closed

A finding is considered fixed only when the change includes a test or command that reproduces the issue and now passes, reviewed by someone other than the author.
